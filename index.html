实验说明

实验中选取 GitHub 作为云环境。GitHub 仓库保存站点源文件，每次向指定分支推送提交后， GitHub Pages 会自动拉取最新内容并分发到全球 CDN 节点，对外提供 HTTPS 访问， 无需自行购买域名、配置服务器或申请证书。

页面只用到了 HTML 与 CSS，属于纯静态内容，因此无需后端运行时与数据库， 这也是本实验选择静态托管方案的主要原因。
